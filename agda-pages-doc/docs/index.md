# Agda-Pages

Agda-Pages supports **generation of websites** with **module navigation**
between **highlighted, hyperlinked listings** of **plain** and **literate**
Agda code.

See the **[About]** page for an overview of the supported features of
generated websites, and for links to examples.

The **[User Guide]** explains how to generate a website listing the Agda code
in any GitHub repository.

The **[Agda-Pages-Demo]** website illuatrates and tests use of the 
latest release of Agda-Pages.
